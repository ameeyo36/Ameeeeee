# Figure → 可編輯 PowerPoint

將上傳的 figure、AI 圖片、海報或投影片截圖，分層重建為可編輯的 PPTX。

## 使用方式

載入本資料夾的 SKILL.md 後，上傳原圖並輸入：

```text
使用 $figure-to-editable-ppt-reconstruction，將這張圖還原成可編輯 PPT。
保留原文、原始比例、配色與布局，提供預覽及重建報告。
```

## 工作流程

1. 辨識文字、圖片、icon、形狀與圖表。
2. 分析重疊、遮擋及前後順序。
3. 以原生文字框、形狀、線條及表格重建。
4. 將複雜插畫保留為獨立圖片物件。
5. 渲染 PPTX，與原圖比對並修正差異。

## 輸出

可編輯 PPTX、預覽 PNG、疊圖、差異圖與 JSON 重建報告。

## 環境與限制

這是供 AI 代理載入的技能指引，並非獨立轉檔程式。執行環境需提供圖片檢視、PPTX 製作及渲染工具。

單張圖片無法保證恢復原始字型、被遮住的像素及全部圖層資訊。圖片可移動、縮放與替換，但內部細節不等同原生向量可編輯。不會捏造圖表數據，未完成項目會明確標示，不宣稱 100% 還原。
